# FactoryTraj-Bench v0.1 Contract Pack

| Artifact | Purpose |
|---|---|
| `factorytraj_item.schema.json` | Canonical benchmark item |
| `factorytraj_output.schema.json` | Structured model prediction |
| `FACTORYTRAJ_DATA_CONTRACT.md` | Field semantics and protocol |
| `factorytraj_task_contracts_v0.1.json` | Machine-readable B0-B10 definitions |
| `FACTORYTRAJ_TASK_CONTRACTS.md` | Capability, metric and gate rationale |
| `factorybench_samples_v0.1.json` | Ten research-only L1-L4 examples |
| `factorytraj_validation_report_v0.1.json` | Latest sample validation |
| `factorytraj_task_contracts_validation_v0.1.json` | Latest task validation |
| `b0_seed_v0.1.json` | FactoryNet-derived B0 research seed |
| `b0_seed_results_v0.1.json` | B0 baseline, coverage and admission results |
| `B0_SEED_REPORT.md` | Human-readable B0 diagnosis and next requirements |
| `b0_pass_threshold_v0.1.json` | Frozen B0 model pass criteria |
| `opcua_public_probe_v0.1.json` | Live public OPC UA connectivity/metadata probe |
| `b0_opcua_export_template.csv` | Template for a real machine tag export |

This package is a Phase-I benchmark contract, not a commercial training
dataset. FactoryBench-derived content remains subject to CC BY-NC 4.0.
